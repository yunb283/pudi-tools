柔面 · 生成器参数

迭代次数：控制画布上绘制的矩形数量；只沿 X 或 Y 对称时乘以 2，X 与 Y 同时对称时乘以 4。默认 100。

子迭代次数：控制额外以 X 形排布的矩形数量，同样会随对称方式成倍增加。默认 50。

分割器迭代次数：控制以 + 形排布的矩形数量，无论对称设置如何都会乘以 2。默认 50。

背景亮度：控制贴图底色。用于置换时，设为 0 会让整体向外凸起，255 则相反。默认 128。

对称轴向：选择 X 与 Y、仅 X、仅 Y 三种对称方式。默认 X 与 Y。

启用分割器：是否叠加 + 形的分割层。默认开启。

分割器差值混合：是否对 + 形分割层使用差值混合。默认开启。
